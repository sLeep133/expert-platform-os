# 常见问题

## Q1: 编译 Wiki 时提示"PDF 文件读取失败"？

**原因**：pypdf 无法解析某些 PDF 格式（如扫描版或图片 PDF）。

**解决**：已在最新版本中修复。系统会检查文件头魔数，非标准 PDF 自动 fallback 到文本读取。请更新到最新版本：
```bash
cd expert-platform-os
git pull origin main
docker compose -f docker-compose.webui-only.yaml up -d --build
```

## Q2: 编译成功但专家回答不引用 Wiki 内容？

**原因**：LLM API 配置无效（如 MiniMax 过期、模型不存在）。

**解决**：
1. 检查 Docker 日志：`docker logs open-webui | grep "Step 1 analysis failed"`
2. 在 OpenWebUI 设置中更换有效的 API Key 和模型
3. 或在专家编辑页面设置该专家专用的 `runtime_model`

## Q3: Wiki 编译按钮一直转圈？

**原因**：前端状态轮询延迟，实际编译可能已完成。

**解决**：刷新页面即可看到最新状态。若持续失败，检查日志中是否有 LLM API 报错。

## Q4: 如何导出 Wiki 到 Obsidian？

Wiki 目录位于容器内 `/app/backend/data/knowledge/{knowledge_id}/wiki/`，格式为原生 Markdown + `[[wikilinks]]`。

导出方式：
```bash
docker cp open-webui:/app/backend/data/knowledge/{knowledge_id}/wiki ./my-vault
```
然后将 `wiki/` 目录复制到 Obsidian vault 即可直接使用。

## Q5: 支持哪些文件格式？

| 格式 | 支持状态 |
|------|---------|
| PDF | 支持（文字版优先，扫描版 fallback 到文本） |
| Word (.docx) | 支持 |
| Excel (.xlsx/.csv) | 支持 |
| Markdown / 文本 | 直接读取 |
| 网页 / 图片 | 通过 OpenWebUI 原生 RAG 处理 |
