# 快速开始

## 1. 部署

```bash
git clone https://github.com/sLeep133/expert-platform-os.git
cd expert-platform-os
docker compose -f docker-compose.webui-only.yaml up -d
```

访问 http://localhost:3000，注册管理员账号。

## 2. 配置大模型

1. 进入右上角「设置」→「外部连接」
2. 添加 OpenAI 兼容 API：
   - API Base: `https://api.moonshot.cn/v1`（Kimi 示例）
   - API Key: 你的 Key
   - Model: `kimi-k2.6`
3. 保存后，在模型列表中确认已启用

## 3. 创建知识库

1. 进入「工作空间」→「知识库」
2. 点击「新建知识库」，命名（如"人工智能"）
3. 进入知识库，上传 PDF/Word/Excel 文件
4. 等待文件处理完成后，点击「编译 Wiki」
5. 编译成功后，下方会展示生成的 Wiki 页面列表

## 4. 创建专家

1. 进入「工作空间」→「专家」
2. 点击「创建专家」，填写：
   - 名称：如"人工智能专家"
   - 角色：如"深度学习导师"
   - 知识关联：勾选刚才创建的知识库
3. 保存后，点击「开始聊天」测试

## 5. 测试问答

选择「人工智能专家」，提问：
> "什么是张量？自动微分在深度学习中起什么作用？"

对比不选专家时的回答，观察质量差异。
